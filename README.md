# Практическое занятие №1. Командная строка

Дисциплина «Конфигурационное управление». Все решения — на bash (`#!/usr/bin/env bash`,
`set -euo pipefail`, переменные в кавычках — чтобы ShellCheck не выдавал предупреждений).
Запуск: `chmod +x *.sh`, затем `./имя_скрипта.sh`.

|---|------|---------------|

| 3 | `banner.sh` | `./banner.sh "Hello from RTU MIREA!"` |

## Решения и пояснения

**Задача 1.** `grep -o '^[^:]*' /etc/passwd | sort` — `grep -o` вырезает первое поле
(до `:`), `sort` сортирует по алфавиту (`LC_ALL=C` — стабильный порядок).

**Задача 2.** Строка `/etc/protocols`: `имя номер АЛИАС # комментарий`.
Убираем комментарии (`grep -v '^#'`), `awk` меняет поля местами (`номер имя`),
`sort -rn` — численная сортировка по убыванию, `head -n 5` — пять наибольших.
Результат зависит от версии файла в системе (в примере задания самый большой — 142 `rohc`;
в более новых дистрибутивах есть ещё 143 `ethernet`, 262 `mptcp`).

**Задача 3.** Ширина рамки = длина текста + 2 пробела; строка из `-` строится через
`printf '%*s'` + `tr`. Несколько аргументов склеиваются через `"$*"`. Длина считается в
символах (UTF-8), поэтому кириллица тоже выравнивается. Вывод:

```
$ ./banner.sh "Hello from RTU MIREA!"
+-----------------------+
| Hello from RTU MIREA! |
+-----------------------+
```

**Задача 4.** Идентификатор по правилам C/C++/Java — `[A-Za-z_][A-Za-z0-9_]*`.
`grep -oE` извлекает все совпадения (границы слова `\b` не дают взять `x1F` из `0x1F`),
`sort -u` убирает повторы, `paste -sd' '` склеивает в одну строку. Как и в примере из
задания, ключевые слова не отфильтровываются, а `n` берётся из `\n`.

**Задача 5.** `install -m 0755 файл /usr/local/bin/` — одновременно выставляет права
`rwxr-xr-x` и копирует. Нужны права root (`sudo`); для тестов каталог можно подменить
переменной `REG_DEST`. Проверяются аргумент, существование файла и доступ на запись.

**Задача 6.** Рекурсивный `find` по `*.c`, `*.js`, `*.py`; читается первая строка.
Для `c`/`js` комментарий — `//` или `/*`, для `py` — `#` (shebang `#!` тоже начинается с `#`
и засчитывается). Печатает `OK`/`NO` для каждого файла; код возврата 1, если есть файлы без
комментария.

**Задача 7.** `find -type f` → `sha256sum` → `sort` → `awk` группирует подряд идущие
одинаковые хеши и печатает группы из ≥2 файлов. Имена с пробелами обрабатываются
корректно (`-print0` / `xargs -0`). Пустые файлы тоже считаются дубликатами друг друга.

**Задача 8.** `find` по маске `*.расширение` (рекурсивно, точка в расширении
необязательна) → `tar --null -T -`. Пути в архиве относительные, сам архив в список не
попадает. Если файлов нет — сообщение и код 1.

**Задача 9.** `sed 's/ \{4\}/<TAB>/g'`: каждая группа из 4 пробелов → один символ табуляции
(8 пробелов → 2 табуляции). Входной и выходной файлы не должны совпадать.

**Задача 10.** `find КАТАЛОГ -type f -empty -name '*.txt'` — пустые текстовые файлы
(по умолчанию `*.txt`, маску можно передать вторым аргументом, например `'*'` для всех пустых).

## Сравнение командной строки Windows и Linux

| Действие | Linux (bash) | Windows (cmd) | Windows (PowerShell) |
|----------|--------------|---------------|----------------------|
| Список файлов | `ls -l` | `dir` | `Get-ChildItem` (`ls`, `dir`) |
| Сменить каталог | `cd` | `cd` | `Set-Location` (`cd`) |
| Вывести файл | `cat f` | `type f` | `Get-Content f` |
| Копировать | `cp a b` | `copy a b` | `Copy-Item a b` |
| Удалить | `rm f` | `del f` | `Remove-Item f` |
| Поиск в тексте | `grep` | `findstr` | `Select-String` |
| Сортировка | `sort` | `sort` | `Sort-Object` |
| Поиск файлов | `find` | `dir /s` | `Get-ChildItem -Recurse` |
| Права доступа | `chmod`, `chown` | `icacls` | `Get-Acl` / `Set-Acl` |
| Разделитель пути | `/` | `\` | `\` (и `/`) |
| Конвейер | текстовый поток | текстовый поток | поток **объектов** |
| Регистр имён файлов | различается | не различается | не различается |
